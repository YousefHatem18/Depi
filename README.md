# TechZone Demo Data

This folder contains fictional data for the Customer Support AI Agent.

Files:
- products.json: product details, prices, stock, warranty
- customers.json: demo customer records
- orders.json: demo orders and delivery/payment status
- policies.json: refund, replacement, delivery, and warranty rules
- tickets.json: support tickets created by the agent

Important test cases:
- ORD1001: delivered headphones, useful for broken-product/refund workflow
- ORD1002: shipped smartwatch
- ORD1003: delivered keyboard, currently out of stock
- ORD1004: processing mouse order
- ORD1006: cancelled and already refunded order
